# 贈与税いくら？（zoyozei-ikura）

1年間にもらった額と、だれからもらったか（父から25歳の子 300万円・夫から妻 500万円・友人から 1,000万円 など）を読んで、贈与税の額を当てる1日5問の学習ゲーム。正解したら「どちらの表？」（一般税率・特例税率・かからない）も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/zoyozei-ikura/>

- 答えは、国税庁タックスアンサー No.4408「贈与税の計算と税率（暦年課税）」の速算表（1年間にもらった額−基礎控除110万円＝基礎控除後の課税価格。それ×税率−控除額）から計算しています（［令和8年4月1日現在法令等］。2026-11-17 に読みました）。
  - <https://www.nta.go.jp/taxes/shiraberu/taxanswer/zoyo/4408.htm>
- 相続時精算課税・配偶者控除・住宅取得資金などの非課税・一般と特例が混ざる年・申告の手続きは出しません。人と金額はつくりものです。
- このゲームは贈与税のしくみを知る練習です。税の相談の代わりではありません。実際の税額は、国税庁の資料や税務署で確かめてください。
